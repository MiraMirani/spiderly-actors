# Actor icons

The current Actor avatars are the 512 × 512 PNGs in `spiderly-large/`. They match the approved LinkedIn size test: the larger complete Spiderly mascot, with visible legs and no enclosing circle, paired with the relevant platform mark. Use the same FINN icon for both FINN Actors. `spiderly-large/jobs.png` is the fallback for future platforms. `spiderly-large/preview.png` shows the full set, `thumbnail-preview.png` shows 40px versions, and `prompts.md` records the built-in image-generation prompts.

The plain platform PNGs and editable SVGs below are preserved as source references. They use a white background and consistent spacing.

- `finn.png`: FINN's compact brand mark, used for both FINN Actors. [Source SVG](https://assets.vend.com/pkg/@warp-ds/brand-logos/~1/finn-small.svg), linked from [FINN.no](https://www.finn.no/).
- `linkedin.png`: LinkedIn's blue “in” mark. [Source SVG](https://static.licdn.com/aero-v1/sc/h/akt4ae504epesldzj74dzred8), linked as the favicon on [LinkedIn](https://www.linkedin.com/).
- `nav.png`: NAV's red circular mark. [Source SVG](https://cdn.nav.no/personbruker/nav-dekoratoren/public/favicon.svg), linked from [NAV](https://www.nav.no/).
- `jobbnorge.png`: Jobbnorge's coral symbol, extracted from its current wordmark without changing the path. [Source SVG](https://www.jobbnorge.no/search/img/logo/logo-grade-jobbnorge.svg), linked from [Jobbnorge](https://www.jobbnorge.no/).
- `jobs.png`: an original purple briefcase icon, used as the default for future sites without a dedicated icon.

Source marks were retrieved on 2026-11-05. Their respective owners retain rights to them. They identify the sources supported by these independent Actors.

The original Spiderly mascot remains available in `assets/spiderly-icon.png`. The previous compositions in `spiderly/` and all plain source files remain available. The combined PNGs are separate bitmap assets.
